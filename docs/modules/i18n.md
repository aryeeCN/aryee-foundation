# Aryee Foundation I18n

> **所属项目**: [Aryee Foundation](../../README.md)
> **类型**: 国际化基础设施模块
> **技术栈**: Java 21, Spring Boot 4.0.7, Spring MessageSource, Reactor
> **主包**: `cn.aryee.i18n.api`

国际化基础设施模块，提供 Spring MessageSource 集成、Locale 解析、ErrorCode→i18nKey 解析链路，支持 Blocking 与 Reactive 双模式。

## 核心特性

- ✅ **Spring MessageSource 集成**: 通过 `SpringMessageSourceProvider` 将 Spring `MessageSource` 桥接到 commons-core 的 `I18nUtil`，让无 Spring 依赖的代码也能使用 Spring 容器内的国际化资源
- ✅ **ErrorCode→i18nKey 解析链路**: `ErrorCode.getI18nKey()` → `I18nUtil.t()` → `SpringMessageSourceProvider` → Spring `MessageSource` → 资源文件，自动国际化错误消息
- ✅ **GlobalException 自动国际化**: `GlobalException.getLocalizedMessage()` 自动通过 i18n 链路解析本地化消息
- ✅ **R 响应自动国际化**: `R.fail(ErrorCode)` 等工厂方法自动调用 `ErrorCode.getLocalizedMessage()`，返回国际化的错误消息
- ✅ **多种 Locale 解析策略**: Accept-Language（默认）/ Cookie / Session / Fixed / Composite，支持 `@ConditionalOnMissingBean` 覆盖
- ✅ **双模式隔离**: Blocking（WebMVC，基于 ThreadLocal）+ Reactive（WebFlux，基于 Reactor Context）严格分层，独立 Starter
- ✅ **默认资源文件**: 提供 `messages.properties` / `messages_en.properties` / `messages_zh.properties` / `messages_zh_CN.properties`，覆盖 commons-core ErrorCodeEnum 核心错误码
- ✅ **可扩展 basename**: 业务模块可通过 `aryee.i18n.additional-basenames` 注册多个资源文件
- ✅ **动态翻译管理**: 运行时增删改翻译（`I18nMessageService`），优先于资源文件、修改即时生效，无需重启
- ✅ **翻译管理 REST API**: 开箱即用的翻译 CRUD + 前端资源导出 + 语言偏好管理端点
- ✅ **模板翻译**: `I18nTemplateService` 面向邮件/短信/通知场景，命名占位符 `{name}` 渲染
- ✅ **用户语言偏好持久化**: `LocalePreferenceService` + `LocaleUserIdProvider` SPI，偏好优先于自动解析
- ✅ **前端资源导出**: `I18nResourceExportService` 聚合资源文件 + 动态翻译导出 JSON，供前端 i18n 框架加载
- ✅ **错误码体系**: 独立错误码段 8000~8999（`I18nErrorCodeEnum`）
- ✅ **智能启动诊断**: 启动时清晰展示 Locale 解析策略、默认语言、支持语言列表及功能状态（动态翻译/偏好持久化/REST API）

## 架构定位

- **依赖方向**: `Starter → Autoconfigure → Infrastructure → API`
- **公共基础**: 依赖 `commons-core`（复用 `I18nUtil` / `ErrorCode` / `GlobalException` / `R`）
- **版本管理**: 由 `aryee-foundation-bom` 统一管理，子模块依赖禁止声明 `<version>`
- **双模式隔离**: Blocking 与 Reactive 使用独立的 Starter / Autoconfigure 模块，用户二选一引入

## 使用方法

### Maven 依赖

#### Blocking 模式（默认，Servlet / WebMVC 场景）

```xml
<dependency>
    <groupId>cn.aryee.foundation</groupId>
    <artifactId>i18n-spring-boot-starter</artifactId>
</dependency>
```

#### Reactive 模式（WebFlux 场景）

```xml
<dependency>
    <groupId>cn.aryee.foundation</groupId>
    <artifactId>i18n-reactive-spring-boot-starter</artifactId>
</dependency>
```

> - 版本由 BOM 统一管理，无需声明 `<version>`。
> - Blocking 与 Reactive Starter 禁止同时引入。

### 配置选项

`I18nProperties` 配置前缀：`aryee.i18n`，所有字段均提供默认值，零配置可启动。

```yaml
aryee:
  i18n:
    enabled: true                       # 是否启用 i18n 模块（默认 true）
    default-locale: zh_CN               # 默认语言（默认 zh_CN）
    fallback-locale: en                 # 兜底语言（默认 en）
    basename: i18n/messages             # 资源文件 basename（默认与 commons-core I18nUtil 对齐）
    additional-basenames:               # 额外的 basename（业务模块可注册多个资源文件）
      - i18n/messages-business
    encoding: UTF-8                     # 资源文件编码（默认 UTF-8）
    cache-seconds: 3600                 # 资源文件缓存秒数（默认 3600，-1 永久缓存）
    always-use-message-format: false    # 是否始终使用 MessageFormat 格式化（默认 false）
    use-code-as-default-message: false  # 找不到消息时是否返回 code（默认 false）
    locale-resolver: header             # Locale 解析策略：header | cookie | session | fixed | composite
    cookie-name: aryee-lang             # Cookie 模式的 Cookie 名（默认 aryee-lang）
    cookie-max-age: 7d                  # Cookie 过期时间（默认 7d）
    supported-locales:                  # 支持的语言列表
      - zh_CN
      - en
    reactive:                           # Reactive 模式专属配置
      context-key: aryee.locale         # Reactor Context 中存储 Locale 的键
```

### Locale 解析策略对比

| 策略 | 实现类 | 适用场景 |
|------|--------|----------|
| `header` | `AcceptHeaderLocaleResolver` | 浏览器/移动端自动识别（默认） |

## 核心能力

### 1. ErrorCode→i18nKey 解析链路

引入 i18n 模块后，所有实现 `ErrorCode` 接口的错误码（如 `ErrorCodeEnum`、各模块 `XxxErrorCodeEnum`）的 `getLocalizedMessage()` 会自动通过 i18n 链路解析本地化消息：

```
ErrorCodeEnum.PARAMETER_REQUIRED.getLocalizedMessage()
    ↓
ErrorCodeEnum.getLocalizedMessage()  // 调用 I18nUtil.t(i18nKey, defaultMessage)
    ↓
I18nUtil.t()                          // 优先使用 MessageProvider
    ↓
SpringMessageSourceProvider           // 桥接到 Spring MessageSource
    ↓
Spring MessageSource                  // 查找资源文件
    ↓
messages_zh_CN.properties             // 返回 "参数必填"
```

### 2. GlobalException 自动国际化

```java
// 抛出异常时使用 ErrorCode
throw new BusinessException(ErrorCodeEnum.PARAMETER_REQUIRED);

// 捕获后获取本地化消息（自动根据当前请求 Locale 解析）
try {
    // ...
} catch (GlobalException e) {
    // 自动国际化：返回 "参数必填"（zh_CN）或 "Parameter Required"（en）
    String localizedMessage = e.getLocalizedMessage();
}
```

### 3. R 响应自动国际化

```java
@RestController
@RequestMapping("/api/users")
public class UserController {

    @GetMapping("/{id}")
    public R<UserVO> getUser(@PathVariable Long id) {
        UserVO user = userService.findById(id);
        if (user == null) {
            // R.fail(ErrorCode) 自动国际化
            // 中文请求返回：{"code":1200,"msg":"用户不存在"}
            // 英文请求返回：{"code":1200,"msg":"User Not Found"}
            return R.fail(ErrorCodeEnum.USER_NOT_FOUND);
        }
        return R.ok(user);
    }
}
```

### 4. 使用 I18nService（Blocking 模式）

```java
@Service
@RequiredArgsConstructor
public class MessageService {

    private final I18nService i18nService;

    public String getWelcomeMessage(String username) {
        // 使用当前请求的 Locale
        return i18nService.getMessage("welcome.message", "Welcome, {0}!", username);
    }

    public String getErrorMessage(ErrorCode errorCode) {
        // 从 ErrorCode 解析本地化消息
        return i18nService.getLocalizedMessage(errorCode);
    }

    public Locale getCurrentLocale() {
        // 获取当前请求的 Locale
        return i18nService.getCurrentLocale();
    }
}
```

### 5. 使用 ReactiveI18nService（Reactive 模式）

```java
@Service
@RequiredArgsConstructor
public class ReactiveMessageService {

    private final ReactiveI18nService reactiveI18nService;

    public Mono<String> getWelcomeMessage(String username) {
        // 响应式获取国际化消息
        return reactiveI18nService.getMessage("welcome.message", "Welcome, {0}!", null, username);
    }

    public Mono<String> getErrorMessage(ErrorCode errorCode) {
        // 响应式从 ErrorCode 解析本地化消息
        return reactiveI18nService.getLocalizedMessage(errorCode);
    }

    public Mono<Locale> getCurrentLocale() {
        // 响应式获取当前请求的 Locale（从 Reactor Context）
        return reactiveI18nService.getCurrentLocale();
    }
}
```

### 6. 自定义 LocaleResolver

```java
@Configuration
public class CustomI18nConfiguration {

    @Bean
    public LocaleResolver localeResolver() {
        // 自定义 Locale 解析器，覆盖默认实现
        return request -> {
            // 从自定义 Header 解析
            String lang = request.getHeader("X-App-Lang");
            if ("zh".equals(lang)) {
                return Locale.SIMPLIFIED_CHINESE;
            } else if ("en".equals(lang)) {
                return Locale.ENGLISH;
            }
            return null;
        };
    }
}
```

### 7. 扩展资源文件（业务模块）

业务模块可在自己的 `src/main/resources/i18n/` 目录下放置资源文件，并通过配置注册：

```yaml
aryee:
  i18n:
    additional-basenames:
      - i18n/messages-business   # 业务模块自定义资源文件
      - i18n/messages-order      # 订单模块资源文件
```

资源文件示例（`i18n/messages-business_zh_CN.properties`）：

```properties
order.created=订单创建成功
order.paid=订单支付成功
order.cancelled=订单已取消
welcome.message=欢迎您，{0}！
```

### 8. 动态翻译管理（运行时增删改，无需重启）

动态翻译优先于 properties 资源文件，修改即时生效。默认内存存储，
生产环境可自定义 `I18nMessageService` Bean 替换为数据库等持久化实现。

```java
// 保存翻译（upsert）
messageService.saveMessage(I18nMessage.builder()
        .key("order.refunded").locale("zh_CN").value("订单已退款").build());
// 全链路自动生效：I18nService / I18nUtil / GlobalException / R.fail
String msg = i18nService.getMessage("order.refunded", "订单已退款", Locale.SIMPLIFIED_CHINESE);
```

### 9. 模板翻译（邮件/短信/通知）

```java
// 模板内容存于消息源：notify.order.paid=尊敬的{name}，您的订单 {orderId} 已支付成功
String text = templateService.render("notify.order.paid", Map.of(
        "name", "Alice", "orderId", "SO20240101"));
```

### 10. 用户语言偏好持久化

用户主动选择的语言优先于 Accept-Language / Cookie 等自动解析策略。
实现自定义 `LocaleUserIdProvider` Bean（如从安全上下文读取登录用户 ID）即可关联登录用户；
默认存储为内存，可自定义 `LocalePreferenceService` Bean 替换为持久化实现。

### 11. 前端资源导出与 REST 管理端点

`GET {base-path}/resources/export?locale=zh_CN` 一次性导出服务端全部翻译（JSON），
供 vue-i18n / react-i18next 等前端框架加载，保证前后端文案一致。

| 方法 | 路径 | 说明 |
|------|------|------|
| GET | `{base-path}/messages?locale=` | 查询动态翻译列表 |
| GET | `{base-path}/messages/key/{key}?locale=` | 查询单条翻译 |
| POST | `{base-path}/messages` | 新增/更新翻译（upsert） |
| DELETE | `{base-path}/messages/key/{key}?locale=` | 删除翻译 |
| GET | `{base-path}/resources/export?locale=` | 导出全部翻译（JSON） |
| GET / PUT / DELETE | `{base-path}/preference` | 当前用户语言偏好查询/保存/删除 |

> REST API 默认开启，生产环境请自行在网关/安全层添加管理员鉴权。

## 默认资源文件

`i18n-spring-boot-starter` 自带以下默认资源文件，覆盖 commons-core `ErrorCodeEnum` 的核心错误码：

| 资源文件 | 语言 | 说明 |
|----------|------|------|
| `i18n/messages.properties` | 英文（fallback） | 默认资源，未匹配到任何 Locale 时使用 |
| `i18n/messages_en.properties` | 英文 | 英文 Locale（en、en-US 等） |
| `i18n/messages_zh.properties` | 中文繁体 | 中文繁体 Locale（zh-TW、zh-HK 等） |
| `i18n/messages_zh_CN.properties` | 简体中文 | 简体中文 Locale（zh-CN） |

覆盖范围：
- 系统错误（-1 ~ -3）
- Commons 系统错误（600 ~ 999）：租户、令牌、客户端、服务器
- 业务错误（1000 ~ 1099）
- 参数校验错误（1100 ~ 1199）
- 通用操作错误（2900 ~ 2999）
- I18n 模块自身错误（8000 ~ 8999）

|--------|--------|----------|----------|
| 8001 | `I18N_RESOURCE_NOT_FOUND` | `i18n.resource.not.found` | 国际化资源文件未找到 |
| 8002 | `I18N_MESSAGE_KEY_NOT_FOUND` | `i18n.message.key.not.found` | 国际化消息键不存在 |
| 8003 | `I18N_LOCALE_RESOLVE_FAILED` | `i18n.locale.resolve.failed` | 语言环境解析失败 |
| 8004 | `I18N_LOCALE_NOT_SUPPORTED` | `i18n.locale.not.supported` | 不支持的语言环境 |
| 8005 | `I18N_RESOURCE_LOAD_FAILED` | `i18n.resource.load.failed` | 国际化资源文件加载失败 |
| 8006 | `I18N_MESSAGE_FORMAT_FAILED` | `i18n.message.format.failed` | 国际化消息格式化失败 |

| 8008 | `I18N_TEMPLATE_RENDER_FAILED` | `i18n.template.render.failed` | 国际化模板渲染失败 |

## 双模式隔离设计

本模块严格遵循 [architecture.md §6.1](https://github.com/aryeecn/aryee-foundation)（内部规范：architecture） 的双模式隔离原则：

| 维度 | Blocking | Reactive |
|------|----------|----------|
| Locale 上下文 | ThreadLocal（`LocaleContextHolder`） | Reactor Context（`ReactiveLocaleContextHolder`） |
| 请求入口 | `LocaleResolverFilter`（OncePerRequestFilter） | `ReactiveLocaleContextWebFilter`（WebFilter） |
| 服务接口 | `I18nService` | `ReactiveI18nService` |
| 解析器接口 | `LocaleResolver`（基于 HttpServletRequest） | `ReactiveLocaleResolver`（基于 ServerWebExchange） |
| 实现包 | `blocking.resolver` / `blocking.service` | `reactive.resolver` / `reactive.service` |
| Autoconfigure | `AryeeI18nAutoConfiguration` | `AryeeI18nReactiveAutoConfiguration` |
| Starter | `i18n-spring-boot-starter` | `i18n-reactive-spring-boot-starter` |
| 配置前缀 | `aryee.i18n` | `aryee.i18n.reactive` |

**共享组件**（两种模式都可装配，通过 `@ConditionalOnMissingBean` 守护）：
- `MessageSource`：基于 `ResourceBundleMessageSource`
- `SpringMessageSourceProvider`：桥接 Spring `MessageSource` 到 `I18nUtil`

## 与 commons-core 的关系

本模块是 commons-core `I18nUtil` 的 Spring 集成层：

| 能力 | commons-core（无 Spring） | i18n 模块（Spring 集成） |
|------|---------------------------|--------------------------|
| 国际化消息解析 | `I18nUtil.t()` 使用 JDK `ResourceBundle` | `I18nUtil.t()` 使用 Spring `MessageSource`（通过 `SpringMessageSourceProvider`） |
| Locale 解析 | JVM 默认 Locale | 请求感知（Header/Cookie/Session） |
| 资源文件加载 | classpath `i18n/messages_*.properties` | Spring `ResourceBundleMessageSource`（支持多 basename） |
| 错误码国际化 | `ErrorCodeEnum.getLocalizedMessage()` 使用默认消息 | `ErrorCodeEnum.getLocalizedMessage()` 使用资源文件消息 |
| 适用场景 | 纯 JDK 库、SDK | Spring Boot 应用 |

> **零侵入设计**：commons-core 中的 `GlobalException`、`ErrorCodeEnum`、`R` 等类无需任何修改，
> 引入 i18n 模块后自动获得 Spring `MessageSource` 集成能力。

## 最佳实践

1. **资源文件命名**：遵循 BCP 47 规范，使用 `messages_{language}_{country}.properties` 格式
2. **避免硬编码消息**：业务代码中应使用 `ErrorCode` + `R.fail(ErrorCode)`，让 i18n 链路自动处理
3. **扩展 basename**：业务模块的资源文件放在自己的 `src/main/resources/i18n/` 目录下，通过 `additional-basenames` 注册
4. **Locale 解析策略**：生产环境推荐 `composite`（Header → Cookie → Session），兼容自动识别和用户手动切换
5. **Reactive 模式**：Locale 通过 Reactor Context 传递，避免在响应式流中使用 ThreadLocal
