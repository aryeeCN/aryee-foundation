# ADR-005: RBAC + ABAC 混合权限模型

## 状态
✅ 已采纳

## 背景
企业级应用需要灵活的权限控制。纯 RBAC 模型在复杂场景下不够用（如按部门、按属性的动态权限），纯 ABAC 又过于复杂。需要一个兼顾易用性和灵活性的混合模型。

## 决策
采用 **RBAC + ABAC 混合权限模型**：

### RBAC 层（基础）
- 角色继承：支持角色间的权限继承
- 角色权限：角色直接拥有的权限
- 用户角色：用户与角色的多对多关系
- 数据权限：按数据范围（全部/本部门/自定义/仅本人）控制

### ABAC 层（扩展）
- 基于属性的访问控制：用户属性 × 资源属性 × 环境属性
- 策略模型：PERMIT/DENY + 优先级
- 条件逻辑：AND/OR/NOT
- 支持自定义评估函数

### 动态权限
- 权限规则热更新（不重启应用）
- 权限模板（快速批量配置）
- 权限变更事件订阅/通知

### 权限判定流程
1. 检查 ABAC 策略优先级高于 RBAC
2. 角色/用户/GLOBAL 三类授权类型
3. 先匹配 DENY 规则，再匹配 PERMIT 规则
4. 支持时间窗口生效（effectiveFrom/effectiveTo）

## 影响
- 覆盖从简单到复杂的权限场景
- 支持权限热更新，无需重启
- 权限变更可通过事件机制通知下游
